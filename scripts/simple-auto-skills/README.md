# simple_auto 办公 skill（IM 自带）

IM 个人助理（meta-agent `simple_auto` 模式）使用的 Word / Excel / PPT / PDF 处理说明，由本项目编写，基于开源库：
python-docx、openpyxl、python-pptx、pypdf、pdfplumber、reportlab，格式转换用 LibreOffice。

`npm run agent:setup-simple-auto` 会把它们安装到 `~/.meta-agent/skills/simple_auto/`（带 `.im-managed` 标记，重新运行时更新）。
